# AACHIP-JTAG-SNIFFER

AACHIP JTAG Sniffer 是 JTAG 通訊觀察與分析工具，協助開發人員檢視 JTAG 訊號、追蹤通訊流程，以及排查硬體連線問題。

## 分析內容

JTAG 通訊主要包含以下訊號：

| 訊號 | 用途 |
| --- | --- |
| TCK | JTAG 時脈 |
| TMS | 控制 TAP 狀態轉換 |
| TDI | 傳入目標裝置的資料 |
| TDO | 目標裝置傳出的資料 |

透過觀察這些訊號，可協助分析 TAP 狀態轉換、指令暫存器（IR）與資料暫存器（DR）的掃描流程。實際解碼及顯示功能以發布版本為準。

## 應用情境

- 觀察 FPGA、CPLD 或其他 JTAG 裝置的通訊。
- 排查接線、時序與資料傳輸問題。
- 協助開發及驗證 JTAG 控制程式。
- 學習 JTAG 協定與 TAP 狀態機。

## 基本使用流程

1. 依版本說明安裝軟體及必要驅動。
2. 確認擷取硬體的輸入電壓範圍與目標裝置相容。
3. 將擷取通道連接至 TCK、TMS、TDI、TDO，並共地。
4. 依軟體設定通道對應、取樣條件與擷取方式。
5. 啟動擷取，再執行要觀察的 JTAG 操作。
6. 檢視擷取結果並進行分析。

## 使用注意事項

- 支援硬體、最高 JTAG 時脈及分析功能，以各版本說明為準。
- 觀察既有 JTAG 通訊時，擷取端應使用輸入模式，避免與原控制器同時驅動訊號。
- 接線應盡量短，避免探測負載影響原有通訊。
- 更新前請先關閉程式並備份設定。
